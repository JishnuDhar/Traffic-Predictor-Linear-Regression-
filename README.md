# Linear Regression based Traffic Predictor 

## Abstract - 
This model takes in the following parameters - 
1. "Rain Possibility (0-1)"
2. "Important Festival (0/1)"
3. "Weekend (0/1)"
4. "Traffic Last Year (0-1)"
5. "Government Holiday (0-1)"
The model then uses these parameters to predict how harsh the traffic would be on that day ranging from 0 to 1, 0 being an empty road and 1 being completely stand-still.

# Body - 
This model was train on an 80:20 set of training / testing data generated using Google's Gemini.
